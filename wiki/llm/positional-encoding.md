# 位置编码（绝对 / 相对 / RoPE）与长文本外推

> tags: llm, positional-encoding, RoPE, 长上下文, 外推
> weight: 1
> updated: 2026-07-30

## 核心结论
自注意力本身对顺序无感，需要位置编码。绝对位置编码给每个位置一个固定/可学习向量加到输入；相对位置编码只关注 token 间距离；RoPE 用旋转矩阵把位置信息乘进 Q/K，attention 分数天然只依赖相对距离，外推长文本更自然。长文本优化手段：RoPE 插值（PI/NTK/YaRN）、滑动窗口注意力、记忆压缩。

## 展开
- **绝对位置**：原始 Transformer 的 sin/cos 函数式（不同频率正弦波，无参数）或 BERT/GPT 的可学习 embedding。缺点：可学习式超出训练长度就没有对应向量，外推差。
- **相对位置**：attention 时加入 i-j 距离的偏置（如 T5 bias、ALiBi 线性衰减惩罚）。ALiBi 外推能力强。
- **RoPE**（主流：LLaMA/Qwen 等）：把 Q、K 向量按维度两两一组旋转，旋转角度 = 位置 × 频率。内积后位置项只剩 (m-n) 的函数——**用绝对位置的实现方式获得相对位置的性质**。优点：不加参数、可配合 KV Cache、外推性质好。
- **长文本扩展**：
  - 位置插值 PI：把超长位置线性压缩回训练范围，少量微调即可；
  - NTK-aware / YaRN：按频率维度非均匀缩放，高频保留（局部精度）、低频插值（远距离）；
  - 滑动窗口注意力（Mistral）：每层只看局部窗口，层叠后感受野扩大；
  - 记忆/上下文压缩：摘要历史、检索式记忆。

## 关键细节 / 易错点
- 追问"为什么 RoPE 外推比可学习绝对位置好"：旋转是连续函数，任意位置都有定义；而 learned embedding 表越界即失效。
- 追问"RoPE 直接外推为什么还是会崩"：超出训练长度后低频维度进入没见过的角度区间，注意力分布漂移，所以需要插值/NTK 缩放。
- ALiBi 和 RoPE 的取舍：ALiBi 外推最稳但表达受限，RoPE 生态和效果综合最好。
