# 安全护栏：敏感词拦截、危机分级与情感边界

> tags: llm-agent, 安全护栏, 敏感词, 危机干预, 分类模型, guardrails
> weight: 4
> updated: 2026-08-04

## 核心结论
护栏做输入输出双侧：规则词库（快、精确，但易被变体绕过）+ 分类模型（语义识别，覆盖隐喻变体）组合——词库粗筛、模型复核。命中后按严重度分级响应：轻度引导纠偏、中度拦截给安抚话术、高危（自伤/危机）直接转人工 + 推送求助资源。输入端用分类模型做实时预警拦截，输出端再兜一层防模型说不合适的话。

## 展开
- **规则词库 vs 分类模型**：词库毫秒级、可解释，但漏变体/谐音/隐喻且误杀正常词；分类模型（小模型微调）理解语义覆盖变体，成本略高。生产组合：词库短路明显 case → 模型判边界 case → 低置信走大模型或人工。
- **命中后的处理链路**：拦截当前输入/输出 → 替换为安全话术（不生硬拒绝，给共情 + 引导）→ 记录事件 → 按级别决定是否通知人工/限制功能。
- **危机场景分级（心理咨询类 Agent 高频考点）**：如分三级——L1 一般负面情绪（正常对话 + 关注）；L2 自伤暗示（预警、主动关怀话术、提示人工可介入）；L3 明确危机（立即转人工、推送危机干预热线/资源，停止常规闲聊）。分级靠分类模型 + 关键词双通道，宁可误报不可漏报。
- **输入端实时预警**：独立分类模型与主链路并行跑（不增加主链路延迟），命中高危即接管响应。
- **用户刻意回避/撒谎的感知**：多源一致性校验——量表结果 vs 对话文本表达矛盾时标记；追问确认策略（换角度重问）；不强行戳穿，策略上转为更温和的开放式探询。
- **过度共情/情感依赖控制**：prompt 明确边界——声明 AI 身份、不做排他性情感承诺（"只有我理解你"类话术禁止）、鼓励现实社交与专业求助、对话频率/深度异常时主动降温和转介。

## 关键细节 / 易错点
- 追问"为什么输入输出都要拦"：只拦输入防不住模型自己生成不当内容（被诱导/幻觉）；只拦输出则高危输入仍进入上下文影响后续。
- 追问"词库误杀怎么办"：白名单 + 上下文窗口判定（模型复核），bad case 回流迭代。
- 高危场景的设计原则：漏报代价 >> 误报代价，阈值向召回倾斜。
