# 合格 Agent 需要具备的特性

> tags: llm-agent, 可靠性, 可观测性, 自纠错, 上下文管理
> weight: 1
> updated: 2026-07-30

## 核心结论
六个特性：任务执行稳定（同类输入结果一致）、工具调用准确（选对工具+参数正确）、上下文管得住（长对话不丢关键信息）、出错能自纠（失败后自我修正）、可观测（每步决策可追溯）、被打断能得体恢复（中断/插话后状态不乱）。

## 展开
- **稳定性**：相同任务多次执行结果一致（低随机性），成功率有 SLA；靠低 temperature、结构化输出、评测集回归保障。
- **工具调用准**：意图→工具映射正确、参数从上下文正确抽取；错误工具调用是 Agent 最常见故障源。
- **上下文管理**：长任务中关键约束不被冲淡（摘要压缩、重要信息重申），多轮后不忘最初目标；上下文窗口满时有裁剪策略。
- **自纠错**：工具报错/结果不符合预期时能识别并换路（重试、换工具、改参数），而不是把错误结果当真往下走。
- **可观测**：完整 trace（每步的 prompt、决策、工具入出参、耗时、token），线上问题可复现定位；有指标大盘（成功率、平均步数、成本）。
- **可中断恢复**：用户打断、插入新要求、系统重启后，能基于已保存状态得体续作，不重头再来也不错乱。
- 可补充：**安全边界**（高危操作确认、权限最小化）和**成本可控**（步数/token 上限）。

## 关键细节 / 易错点
- 面试时这题答"特性清单"不够，最好每条带一个"怎么实现/怎么度量"。
- 追问"怎么度量 Agent 好坏"：任务完成率、工具调用准确率、平均步数/成本、人工接管率。
- 追问"自纠错怎么实现"：错误 observation 回传 + reflection 提示；上限控制防死循环。
