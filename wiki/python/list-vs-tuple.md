# Python 列表与元组的区别

> tags: python, list, tuple, 数据结构
> weight: 1
> updated: 2026-08-04

## 核心结论
核心区别是可变性：list 可变（增删改），tuple 不可变。由此派生：tuple 可哈希（能当 dict key / 进 set，前提元素都可哈希）、有常量优化（创建迭代略快、内存略省）、语义上表达"不应被修改"的记录。

## 展开
- **可变性**：list 有 append/extend/pop 等修改方法；tuple 创建后不可改（改元素报错），但 tuple 里的可变元素（如 list）内部仍可改——"不可变"是浅层的。
- **哈希性**：tuple 全部元素可哈希时整体可哈希 → 可作 dict key、set 元素；list 不可哈希。
- **性能**：tuple 创建快、内存少（定长不预留扩容空间）、可被解释器常量折叠；差异微小，选型主要看语义不看性能。
- **语义与场景**：
  - list：同质元素集合，长度会变（队列、结果集）；
  - tuple：异质固定结构记录（坐标 (x, y)、函数多返回值、数据库一行）；
  - 需要 dict key / 保证不被改 → tuple。
- 相关：namedtuple 是带字段名的 tuple，兼顾可读性。

## 关键细节 / 易错点
- 追问"tuple 真的不可变吗"：浅不可变——`t = (1, [2]); t[1].append(3)` 合法。
- 追问"函数返回多个值是什么"：本质是返回一个 tuple，解包赋值。
